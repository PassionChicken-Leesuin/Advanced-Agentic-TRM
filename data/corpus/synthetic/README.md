# 가상 내부자료 (synthetic internal documents) — 전부 허구

이 폴더의 문서 50건은 연구용으로 **LLM이 생성한 허구의 내부 문서**입니다 (회의록, R&D 주간보고, 고객·공급사 메일, 기술평가서).
IonQ의 실제 내부 문서가 아니며, 문서 안의 수치·일정·고객명·공급사명·의사결정은 모두 지어낸 것입니다.
생성 근거는 `../../facts_ledger.json`(사전에 정한 가상 사실 42건)이고, 생성 절차는 `trmkb/corpus/synth.py`에 있습니다.
사람 이름은 쓰지 않고 역할명만 사용했습니다.

These 50 documents are **fictional, LLM-generated** internal documents created for research. They are not real IonQ records;
all figures, dates, customers, suppliers and decisions are invented (see `facts_ledger.json`). No real personal names are used.
